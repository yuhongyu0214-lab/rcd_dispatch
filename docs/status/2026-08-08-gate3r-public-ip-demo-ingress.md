## 2. 用户批准的展示边界

当前阶段采用“公网 IP 预生产演示”，暂不购买域名、不办理备案、不申请正式域名证书：

- 允许其他电脑和不同网络通过现有公网 IP 访问受控演示环境；
- 保留 HTTPS，不降级为传输登录凭据的纯 HTTP；
- 接受自签名证书产生的浏览器警告，不以跳过证书检查作为正式验收；
- 只使用演示或脱敏数据，不承载正式客户、真实生产业务或公开注册；
- 公网只开放 Nginx 必要端口，app、worker、RDS、Tair 和 migration 不直接暴露；
- 不得把当前入口称为“正式上线”或“浏览器可信 HTTPS”。

正式域名、适用备案/许可核验和受信任证书延后到正式生产切换前完成。若云平台或适用规则不允许当前展示方式，应立即停止对外展示，不得绕过限制。
